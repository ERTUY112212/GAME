这是一个基于 Python 和 Pygame 库开发的**本地双人同屏对抗**射击游戏。红队与蓝队在各自的半场进行激烈的空战对决，率先击毁对方飞机的队伍将获得胜利！

#### 游戏特色

- **本地双人同屏**：无需联网，一台键盘即可双人同乐。
- **阵营对抗**：红队（左侧）VS 蓝队（右侧），各自坚守阵地。
- **实时血条系统**：直观展示双方剩余生命值。
- **完整游戏流程**：包含射击、碰撞检测、胜负判定以及游戏重置功能。

#### 游戏玩法规则

1. **活动范围**：红队只能在屏幕左半边（中线左侧）活动，蓝队只能在屏幕右半边（中线右侧）活动。
2. **攻击机制**：红队子弹向上飞行，蓝队子弹向下飞行。子弹击中对方飞机会扣除 **10点** 生命值。
3. **获胜条件**：双方的初始生命值均为 **100**。当任意一方的生命值降为 0 时，游戏结束，另一方获胜。

#### 代码结构说明

- **常量定义**：包含了屏幕分辨率（1200x800）、FPS（60）以及各阵营的颜色定义。
- `**Bullet**`** 类**：负责处理子弹的生成、飞行方向（根据队伍自动判定）以及越界销毁。
- `**Player**`** 类**：继承自 `pygame.sprite.Sprite`，封装了飞机的绘制、移动边界限制、射击冷却时间以及血条绘制逻辑。
- **主循环 (**`**while running**`**)**：处理键盘事件、更新精灵组状态、进行碰撞检测（`spritecollide`）以及渲染游戏画面。
